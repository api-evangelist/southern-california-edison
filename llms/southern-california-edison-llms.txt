# Southern California Edison (SCE)

> Regulated electric utility subsidiary of Edison International serving ~15 million people across a 50,000 square-mile territory in central, coastal and southern California. SCE's API posture splits in two: the CPUC-mandated customer-data interface (Green Button Connect My Data) is real but entirely closed to the open web, while its grid data (Distribution Resources Plan External Portal, DRPEP) is served over an anonymous, key-free Esri ArcGIS REST catalog that any developer can query today. This file was generated by API Evangelist on 2026-07-27 from live probes and the artifacts in this repository; SCE publishes no llms.txt, no developer portal and no OpenAPI.

## What you can actually call

- [SCE DRPEP ArcGIS REST Services](https://drpep.sce.com/arcgis_server/rest/services/Hosted?f=json): Anonymous, unauthenticated. 15 hosted FeatureServers, 47 feature layers and 11 tables of Integration Capacity Analysis, distribution circuits, substations, Grid Needs Assessment, Distribution Deferral Opportunity Report, Locational Net Benefit Analysis, PSPS boundaries, CPUC fire-threat tiers, transmission projects and load heat maps. No key, no registration, no quota.
- [DRPEP portal](https://drpep.sce.com/drpep/): The Esri Experience Builder app over those services.
- [DRPEP open data site](https://drpep-sce2.opendata.arcgis.com/): ArcGIS Hub site publishing the same 47 datasets as CSV, GeoJSON, KML and Shapefile, with DCAT-US 1.1 and DCAT-AP 2.1.1 catalog feeds.

## What you cannot call without registering

- [Green Button Connect My Data / Customer Data Access](https://www.sce.com/partners/3rd-party-energy-providers/access-energy-usage-data): Mandated by CPUC tariff Rule 26 (Advice 3087-E, effective 2014-08-29, implementing D.14-05-016). SCE states third parties need OAuth 2.0 and bulk-API capability "consistent with the standard adopted by the North American Energy Standards Board (NAESB)". No base URI, endpoint list, scope list, OpenAPI or sandbox is published anywhere. Access requires registering a Third Party User ID, supplying a Taxpayer Identification Number, accepting the Third Party Registration Terms & Conditions, and passing an SCE-run machine-to-machine connectivity test.
- [Third-party registration](https://www.sce.com/user-registration?userType=4): The registration funnel. There is no developer portal on any sce.com subdomain.
- [Rule 24 demand response FAQs](https://www.sce.com/partners/3rd-party-energy-providers/rule-24-faqs): The separate, also-gated lane for demand response providers.
- [Energy Data Request Program](https://www.sce.com/partners/partnerships/edrp): The government/research lane; the page renders behind an Okta-gated shell.

## How to query it (verified 2026-07-27)

- Count features: `https://drpep.sce.com/arcgis_server/rest/services/Hosted/ICA_Layer/FeatureServer/0/query?where=1%3D1&returnCountOnly=true&f=json` -> `{"count":676467}`
- One circuit's segments: `.../ICA_Layer/FeatureServer/0/query?where=circuit_name%3D%27Acapulco%27&outFields=*&returnGeometry=false&f=json`
- GeoJSON output: append `&f=geojson`
- Page: `&resultOffset=0&resultRecordCount=2000`, then follow `exceededTransferLimit`
- Errors arrive with HTTP 200 and an `error` object - check the body, not the status line.
